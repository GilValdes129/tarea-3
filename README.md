# Primera práctica con Git

Este proyecto corresponde a mi primera práctica utilizando Git y GitHub como herramientas de control de versiones.

El objetivo de esta actividad fue familiarizarme con los comandos básicos de Git, la creación de repositorios y el manejo de archivos dentro de un proyecto de desarrollo web.

## 📚 Temas practicados

- Inicialización de repositorios con `git init`
- Creación y seguimiento de archivos
- Uso de `git add` y `git commit`
- Visualización del estado con `git status`
- Conexión con GitHub
- Manejo básico de ramas y versiones

## 🛠️ Tecnologías utilizadas

- Git
- GitHub
- Visual Studio Code

## 🎯 Objetivo

Comprender el flujo básico de trabajo con Git para aplicarlo posteriormente en proyectos de desarrollo web y trabajo colaborativo.
